Proyecto de práctica de desarrollo web inspirado en la identidad y el universo de Riot Games. Reúne contenido, elementos multimedia y distintas páginas con una navegación compartida.

## Qué incluye

- Página de inicio y presentación.
- Secciones de nosotros, blog, galería y videos.
- Páginas de promociones y combos.
- Página de contacto con formulario visual y mapa.
- Iconografía de Font Awesome y audio local.

## Tecnologías

HTML y CSS, con Google Fonts y Font Awesome. La estructura del repositorio no requiere un framework ni un proceso de compilación.

## Ver el proyecto en tu equipo

```bash
git clone https://github.com/pavoneh/pagina-web-riotgames.git
cd pagina-web-riotgames
```

Abre `index.html` en tu navegador o utiliza Live Server desde Visual Studio Code. No requiere instalación de paquetes ni proceso de compilación. Mantén la conexión a internet para cargar los recursos externos.

## Archivos principales

| Ruta | Contenido |
| --- | --- |
| `index.html` | Página de inicio |
| `nosotros.html`, `blog.html` | Presentación y contenido |
| `galeria.html`, `videos.html` | Secciones multimedia |
| `promociones.html`, `combos.html` | Contenido promocional |
| `contactos.html` | Formulario visual e información de contacto |
| `css/` | Estilos e iconografía |
| `audio/`, `webfonts/` | Audio y fuentes locales |

## Estado actual

El formulario de contacto no está conectado a un backend. La reproducción automática del audio depende de los permisos del navegador; algunas imágenes y fuentes necesitan internet.
